# Mikku

## Student Freelance & Task Marketplace

Mikku is a web application that connects students who need tasks completed with students who can provide freelance services.

## Project Goals

- Student-to-student task marketplace
- Freelance opportunities for students
- Task posting and management
- Student profiles
- Proposal/application system
- Search and filtering
- Secure authentication

## Technology Stack

- HTML
- CSS
- JavaScript
- jQuery
- AJAX
- Node.js
- Express.js
- MongoDB
- Mongoose
